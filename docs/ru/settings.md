# Настройки

← [Указатель документации](./README.md) · → [Уведомления](./notifications.md) · 🏠 [README.ru.md](../../README.ru.md)

Модалка настроек (шестерёнка в сайдбаре / нижняя навигация на мобильных). Код: [`src/components/SettingsModal.tsx`](../../src/components/SettingsModal.tsx). Настройки хранятся в `localStorage` (`max_messenger_settings`) и мержатся с дефолтами из [`src/App.tsx`](../../src/App.tsx), поэтому после обновлений новые флаги подхватывают значения по умолчанию сами.

## Вкладки

| Вкладка | Что настраивается |
|---|---|
| 🌐 Интерфейс и язык | Язык RU/EN, горячая клавиша отправки, размер шрифта, форматирование телефонов, быстрые ответы |
| 🔔 Звук и уведомления | Звук, каналы уведомлений, разрешение браузера, проверка — [детально](./notifications.md), [якорь](#звук-и-уведомления) |
| 📡 Шлюз и связь | idInstance / токен / URL шлюза, проверка статуса, диагностика очереди, интервал опроса — [якорь](#шлюз-и-связь) |
| 🧩 Интеграция MAX | Iframe-виджет, URL-параметры, postMessage SDK для CRM |
| 💾 Данные и аккаунт | Экспорт JSON, очистка истории, выход — [якорь](#данные-и-аккаунт) |

## Интерфейс и язык

- **Язык интерфейса** — Русский / English, применяется мгновенно ко всему UI (словарь [`src/i18n/translations.ts`](../../src/i18n/translations.ts)).
- **Горячая клавиша отправки** — `Enter` (Shift+Enter — новая строка) или `Ctrl+Enter`.
- **Размер шрифта сообщений** — мелкий / стандартный / крупный.
- **Форматирование телефонов** — `+7 (999) 123-45-67` вместо `79991234567`.
- **Быстрые ответы** — кнопка «Настроить» открывает [`QuickRepliesModal`](../../src/components/QuickRepliesModal.tsx): шаблоны с вставкой в поле или отправкой в один клик.

## Звук и уведомления

Состоит из двух карточек.

**1. Звуковые оповещения** — тумблер `soundEnabled` + кнопка «Проверить звук» (синтетический chime через Web Audio API, внешних файлов нет — [`src/utils/sound.ts`](../../src/utils/sound.ts)).

**2. Каналы уведомлений — без задвоения:**

- объяснение правила «один канал за раз» (карточка — когда смотрите на вкладку, системное — когда вкладка в фоне);
- тумблер **«Системные уведомления браузера»** (`browserNotificationsEnabled`);
- тумблер **«Всплывающая карточка внутри вкладки»** (`inAppPopupsEnabled`);
- живой бейдж разрешения (`default` / `granted` / `denied` / `unsupported`) + кнопка **«Включить в браузере»** + подсказка про 🔒 в адресной строке при блокировке + кнопка **«Обновить статус»**;
- кнопки **«Проверить текущее»** (честный тест через боевой роутинг) и **«Проверить системное»** (принудительный тест ОС-канала) с текстовым результатом под ними.

Полное руководство со статусами, таблицей неполадок и ограничениями: [Уведомления](./notifications.md).

## Шлюз и связь

- **Параметры инстанса и шлюза** — редактируемые `idInstance`, `apiTokenInstance` (с показом/скрытием), URL шлюза с пресетами (`api.green-api.com`, `<первые 4 цифры>.api.green-api.com`, `7103.api.greenapi.com`). Кнопка «Применить и сохранить шлюз».
- **Проверка статуса** — кнопка «Проверить статус»: состояние инстанса (`authorized` / `notAuthorized` / `blocked`), настройки вебхуков, длина очереди, тестовый `receiveNotification`.
- **Диагностика и автоисправление:**
  - «Оптимизировать для MAX Web» — включает вебхуки в HTTP-очередь (важно, если вебхуки уходят на внешний URL и очередь пуста);
  - «Очистить очередь» — сброс зависших уведомлений;
  - «Синхронизировать сообщения (24ч)» — подтянуть входящие/исходящие из журнала.
- **Интервал опроса** — 1 сек (быстрый) / 2 сек (стандарт) / 5 сек (экономный). Пауза при пустой очереди, ускорение при пачке.

> Если сообщения вообще не приходят — сначала сюда (очередь/авторизация), а не в [уведомления](./notifications.md): уведомления лишь показывают то, что уже доставлено опросом.

## Интеграция MAX

Панель [`IntegrationPanel`](../../src/components/IntegrationPanel.tsx): встраивание виджетом в iframe, диплинки через URL-параметры (`idInstance`, `apiTokenInstance`, `chatId`/`phone`, `name`, `text`) и двусторонний `postMessage`-мост (`MAX_READY`, `MAX_OPEN_CHAT`, `MAX_SEND_MESSAGE`, `MAX_SYNC_CONTACTS`, `MAX_SET_CREDS` ⇄ `MAX_MESSAGE_RECEIVED`/`MAX_MESSAGE_SENT`).

## Данные и аккаунт

- **Экспорт в JSON** — бэкап диалогов и сообщений (`max-web-backup-<дата>.json`).
- **Очистка** — стереть историю без выхода / полный сброс с выходом (с подтверждениями).
- **Выход** — удаляет ключи инстанса с устройства.
