# Настройки

← [Указатель документации](./README.md) · → [Уведомления](./notifications.md) · 🏠 [README.ru.md](../../README.ru.md)

Модалка настроек (шестерёнка в сайдбаре / нижняя навигация на мобильных). Код: [`src/components/SettingsModal.tsx`](../../src/components/SettingsModal.tsx). Настройки хранятся в `localStorage` (`max_messenger_settings`) и мержатся с дефолтами из [`src/config.ts`](../../src/config.ts) через санитизацию (битые значения из старых версий сбрасываются в дефолт, опрос не падает).

## Вкладки

| Вкладка | Что настраивается |

| 🌐 Интерфейс и язык | Язык RU/EN, горячая клавиша отправки, размер шрифта, форматирование телефонов, тема оформления, быстрые ответы |
| 🔔 Звук и уведомления | Звук, каналы уведомлений, разрешение браузера, проверка — [детально](./notifications.md), [якорь](#звук-и-уведомления) |
| 📡 Шлюз и связь | idInstance / токен / URL шлюза, проверка статуса, диагностика очереди, интервал опроса, фоновая сверка, BFF-прокси, последний вебхук — [якорь](#шлюз-и-связь) |
| 🧩 Интеграция MAX | Iframe-виджет, URL-параметры, postMessage SDK для CRM |
| 💾 Данные и аккаунт | Хранилище ключей, авто-выход, TTL, экспорт/импорт (в т.ч. шифрованный), очистка, выход — [якорь](#данные-и-аккаунт) |

## Интерфейс и язык

- **Язык интерфейса** — Русский / English, применяется мгновенно ко всему UI (словарь [`src/i18n/translations.ts`](../../src/i18n/translations.ts)).
- **Горячая клавиша отправки** — `Enter` (Shift+Enter — новая строка) или `Ctrl+Enter`.
- **Размер шрифта сообщений** — мелкий / стандартный / крупный.
- **Форматирование телефонов** — `+7 (999) 123-45-67` вместо `79991234567`.
- **Тема оформления** — Система / Светлая / Тёмная. Class-based тёмная тема (`@custom-variant dark` в Tailwind v4) с pre-paint инициализацией в `index.html` (без вспышки), слежением за `prefers-color-scheme` в режиме «Система». Палитра централизована в [`src/theme.ts`](../../src/theme.ts) и охраняется тестом-сторожем (`src/theme.test.ts`, падает в CI при светлом токене без `dark:`-пары).
- **Быстрые ответы** — кнопка «Настроить» открывает [`QuickRepliesModal`](../../src/components/QuickRepliesModal.tsx): шаблоны с вставкой в поле или отправкой в один клик.

## Звук и уведомления

Состоит из двух карточек.

**1. Звуковые оповещения** — тумблер `soundEnabled` + кнопка «Проверить звук» (синтетический chime через Web Audio API, внешних файлов нет — [`src/utils/sound.ts`](../../src/utils/sound.ts)).

**2. Каналы уведомлений — без задвоения:**

- объяснение правила «один канал за раз» (карточка — когда смотрите на вкладку, системное — когда вкладка в фоне);
- тумблер **«Системные уведомления браузера»** (`browserNotificationsEnabled`);
- тумблер **«Всплывающая карточка внутри вкладки»** (`inAppPopupsEnabled`);
- живой бейдж разрешения (`default` / `granted` / `denied` / `unsupported`) + кнопка **«Включить в браузере»** + подсказка про 🔒 в адресной строке при блокировке + кнопка **«Обновить статус»**;
- кнопки **«Проверить текущее»** (только карточка + звук, без системного спама) и **«Проверить системное»** (принудительный тест ОС-канала через `showNativeNotification`) с текстовым результатом под ними.

Полное руководство со статусами, таблицей неполадок и ограничениями: [Уведомления](./notifications.md).

## Шлюз и связь

- **Параметры инстанса и шлюза** — редактируемые `idInstance`, `apiTokenInstance` (с показом/скрытием), URL шлюза с пресетами (`api.green-api.com`, `<первые 4 цифры>.api.green-api.com`, `7103.api.greenapi.com`). Кнопка «Применить и сохранить шлюз».
- **Проверка статуса** — кнопка «Проверить статус»: состояние инстанса (`authorized` / `notAuthorized` / `blocked`), настройки вебхуков, длина очереди, тестовый `receiveNotification`.
- **Диагностика и автоисправление:**
  - «Оптимизировать для MAX Web» — включает вебхуки в HTTP-очередь (важно, если вебхуки уходят на внешний URL и очередь пуста);
  - «Очистить очередь» — сброс зависших уведомлений;
  - «Синхронизировать сообщения (24ч)» — подтянуть входящие/исходящие из журнала.
- **Интервал опроса** — 1 сек (быстрый) / 2 сек (стандарт) / 5 сек (экономный). Пауза при пустой очереди, ускорение при пачке.
- **Фоновая сверка журнала** — тумблер (по умолчанию вкл). Добирает пропущенное через `lastIncoming`/`lastOutgoing`/`getChatHistory`, минимум 5 сек на активной вкладке и 10 сек в фоне. Выкл — только long-poll очереди, минимум трафика.
- **BFF-прокси** — тумблер (активен, только если сборка с `VITE_BFF_URL`). Отправка и опрос идут через прокси без токена в браузере. Подробнее: [bff/README.md](../../bff/README.md).
- **Последний вебхук из очереди** — живой тип последнего события long-poll + честная пометка: входящего typing-события в GREEN-API нет (только исходящий `sendTyping`), поэтому «собеседник печатает» из сети прийти не может; индикатор проверяется пунктом «Тест» в меню ⋮ чата.

> Если сообщения вообще не приходят — сначала сюда (очередь/авторизация), а не в [уведомления](./notifications.md): уведомления лишь показывают то, что уже доставлено опросом.

## Интеграция MAX

Панель [`IntegrationPanel`](../../src/components/IntegrationPanel.tsx): встраивание виджетом в iframe, диплинки через URL-параметры (`idInstance`, `apiTokenInstance`, `chatId`/`phone`, `name`, `text`) и двусторонний `postMessage`-мост (`MAX_READY`, `MAX_OPEN_CHAT`, `MAX_SEND_MESSAGE`, `MAX_SYNC_CONTACTS`, `MAX_SET_CREDS` ⇄ `MAX_MESSAGE_RECEIVED`/`MAX_MESSAGE_SENT`).

## Данные и аккаунт

- **Хранилище ключей** — переключатель «Запомнить на этом устройстве»: выкл — ключи только до закрытия вкладки (`sessionStorage`, безопаснее), вкл — `localStorage`. Действует и на уже введённые ключи. Тот же выбор есть на экране входа.
- **Авто-выход при простое** — Выкл / 5 / 15 / 60 мин. Сбрасывается любым движением мыши, клавишей или тачем; по истечении — выход с тостом.
- **Хранить сообщения (TTL)** — Все / 7 / 30 / 90 дней. Просроченное вычищается из памяти и хранилища (в пределах лимита количества из `src/config.ts`).
- **Экспорт в JSON** — бэкап диалогов и сообщений (`max-web-backup-<дата>.json`, токен не выгружается никогда). С паролем — шифрованный AES-GCM файл (`.enc.json`, PBKDF2-SHA256, 200k итераций, код — [`src/utils/backupCrypto.ts`](../../src/utils/backupCrypto.ts)).
- **Импорт бэкапа** — принимает plain и шифрованные файлы (для шифрованных нужен тот же пароль), слияние с дедупликацией по `chatId`/`id` и применением TTL.
- **Очистка** — стереть историю без выхода / полный сброс с выходом (с подтверждениями).
- **Выход** — удаляет ключи инстанса с устройства.
